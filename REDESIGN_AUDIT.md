# REDESIGN AUDIT: H3H-Backgrounds & H3H-AfterDark

**Дата аудита:** 28 октября 2026 г.  
**Проект:** Комплексный редизайн клиентских приложений Nintendo Switch (Main и After Dark).  
**Целевой интерфейсный референс:** `TorrentShopNX` (эргономичный дашборд, карточная модульная сетка, статус-бар, продуманное управление Joy-Con).  
**Режим:** Тестовый (ветка `feature/redesign-ui-torrentshop`, без публикаций стабильных релизов).

---

## 1. Структура проектов и кодовая база

Оба приложения — **H3H-Backgrounds** (Main) и **H3H-AfterDark** (18+) — собираются из единой исходной кодовой базы, расположенной в каталоге `downloader/`:

```
downloader/
├── include/
│   ├── core/
│   │   ├── catalog_manager.hpp    # Парсинг и фильтрация каталога, маппинг TitleID
│   │   ├── config.hpp             # Конфигурация, пути SDMC, проверка TitleID, флаги сборки
│   │   ├── installed_registry.hpp # Управление списком установленных тайтлов и статусов
│   │   ├── installer.hpp          # Атомарная установка, резервное копирование (.bak), откат
│   │   ├── json.hpp               # nlohmann::json
│   │   ├── sha256.hpp             # Контроль целостности хэшей SHA-256
│   │   └── types.hpp              # Структуры данных (GameCatalogEntry, Variant, DownloadTask и др.)
│   ├── platform/
│   │   └── platform_interface.hpp # Интерфейс IPlatform (Switch vs Desktop Mock)
│   └── ui/
│       ├── app.hpp                # Главный координатор приложения, состояние, рендер-цикл
│       ├── i18n.hpp               # Локализация (Русский / English)
│       ├── theme.hpp              # Цветовые токены, геометрия, Cyber-Glass стили
│       └── video_player.hpp       # FFmpeg аппаратный декодер и плеер видеопревью
├── src/
│   ├── core/                      # Реализация CatalogManager, Installer, Sha256
│   ├── platform/                  # switch_platform.cpp (libnx/curl/nifm/fs/swkbd), desktop_platform.cpp
│   └── ui/                        # app.cpp (UI цикл, 2D рендерер SDL2), video_player.cpp
├── romfs/
│   ├── catalog.json               # Встроенный оффлайн-каталог
```

## 2. Технологический стек и система сборки

- **Язык:** C++17 (строгая типизация, RAII, умные указатели).
- **Платформа и фреймворки:**
  - **Nintendo Switch:** devkitA64 (GCC 16.1.0), `libnx` (системные сервисы: `nifm` сеть, `psm` батарея, `swkbd` виртуальная клавиатура, `ns` перечисление установленных тайтлов, `fs` доступ к SDMC).
  - **Графика и UI:** `SDL2`, `SDL2_ttf`, `SDL2_image` (высокопроизводительный кастомный 2D Cyber-Glass рендерер с поддержкой альфа-блендинга, скругленных углов, градиентных неоновых неонов, капсульных прогресс-баров).
  - **Сетевой уровень:** `libcurl` с многопоточной поддержкой SSL/TLS, таймаутами и прогресс-колбэками.
  - **Видеодекодер:** `FFmpeg` (`libavformat`, `libavcodec`, `libswscale`, `libdav1d`).
  - **Система сборки:**
    - Main: `scripts/build_nro.py` -> сборка `H3H-Backgrounds.nro`
    - After Dark: `scripts/build_nro_after_dark.py` (с флагом `-DH3H_AFTER_DARK`) -> сборка `H3H-AfterDark.nro`
    - Утилиты упаковки: `elf2nro`, `nacptool`.

## 3. Полный реестр реализованных функций

1. **Главный экран (Home):**
   - Баннеры, статус сетевого подключения, краткая статистика установленных видеофонов, быстрый переход к разделам.
2. **Мои игры (Installed Manager):**
   - Сканирование локально установленных на консоли тайтлов через сервис `ns:am`.
   - Двухпанельная навигация: список установленных игр слева, варианты видеофонов и иконок справа.
   - Отображение текущего статуса: «Установлен», «Нет видеофона», «Доступно обновление».
   - Установка фона, установка иконки, восстановление из бэкапа (`.bak`), удаление.
3. **Каталог (Catalog):**
   - Полнотекстовый поиск через виртуальную клавиатуру `swkbd` (клавиша `X`).
   - Фильтрация и сортировка: по алфавиту, по числу вариантов, со звуком, только иконки, только установленные, только избранное.
   - Открытие коллекции вариантов игры.
   - Назначение любого видеофона из каталога на любую установленную игру («Game Picker»).
4. **Очередь загрузок (Downloads):**
   - Многопоточная асинхронная очередь скачивания с индикацией скорости (MB/s), размера (MB/MB) и общего прогресса.
   - Возможность отмены и очистки очереди.
5. **Полноэкранный предпросмотр (Fullscreen Preview):**
   - Интерактивный плеер с воспроизведением видео и звука через FFmpeg.
   - Метаданные: название, разрешение, частота кадров, кодек, длительность, автор, размер.
   - Кнопки быстрых действий: установка фона, установка иконки, добавление в избранное (`Y`).
6. **Браузер локальных записей 4IFIR (Recordings Browser):**
   - Сканирование `sdmc:/recordings/` на наличие пользовательских MP4 записей геймплея.
   - Назначение собственной записи в качестве фона игры.
7. **Система избранного (Favorites):**
   - Сохранение любимых вариантов в `sdmc:/switch/H3H-Backgrounds/favorites.json`.
8. **Менеджер хранилища и кэша (Storage & Cache Manager):**
   - Анализ занятого места: фоны (`/recordings/covers/`), иконки (`/recordings/icons/`), кэш миниатюр и превью.
   - Быстрая очистка кэша миниатюр и кэша видео.
9. **Сканер целостности (Integrity Scanner):**
   - Проверка всех установленных видеофонов на соответствие формату MP4, валидность заголовков и повреждения файлов.
   - Пакетное удаление поврежденных видеофонов с предложением восстановить из бэкапа.
10. **Пакетная установка (Batch Multi-Select):**
    - Быстрый выбор нескольких игр и пакетная фоновая загрузка недостающих видеофонов.
11. **Настройки и OTA обновления:**
    - Выбор языка (Русский / Английский).
    - Переключение директорий.
    - Проверка и асинхронная загрузка обновления NRO приложения.

## 5. Механизмы загрузки, обработки и установки контента

- **Сетевые запросы:** `SwitchPlatform::downloadFile` выполняет потоковую загрузку через `libcurl` во временный файл (`.tmp`). Поддерживается SSL, заголовки User-Agent, проверка HTTP-кодов ответа.
- **Безопасная транзакционная установка (Safe Rollback):**
  1. Скачивание во временный файл: `sdmc:/recordings/covers/<TitleID>.tmp`.
  2. Проверка размера и контрольной суммы SHA-256 (если указана в каталоге).
  3. Если файл `<TitleID>.mp4` уже существует — создание резервной копии `<TitleID>.bak`.
  4. Атомарное переименование `.tmp` -> `.mp4`.
  5. При любой ошибке скачивания или повреждении — автоматический откат из `.bak`.
- **Пути контента на SD-карте:**
  - Видеофоны: `sdmc:/recordings/covers/<TITLE_ID>.mp4`
  - Видеоиконки: `sdmc:/recordings/icons/<TITLE_ID>.mp4`
  - Записи геймплея: `sdmc:/recordings/*.mp4`
  - Настройки и кэш: `sdmc:/switch/<APP_NAME>/`

## 6. Хранение данных пользователя и конфигураций

- `favorites.json` — список избранных вариантов.
- `app_config.json` — сохраненный язык интерфейса и пользовательские настройки.
- Резервные копии `.bak` хранятся непосредственно рядом с целевыми файлами, что исключает рассинхронизацию при извлечении SD-карты.

## 7. Существующие ограничения и недостатки старого интерфейса

1. **Устаревшая структура навигации:** 5 вкладок располагались в верхнем текстовом меню без четкой иерархии и визуального фокуса, типичного для современных приставочных интерфейсов.
2. **Отсутствие выделенного раздела для видеоиконок:** Иконки управлялись косвенно через переключатели внутри карточки видеофона, без возможности увидеть каталог всех доступных иконок сразу.
3. **Недостаток модульности на Главном экране:** На домашнем экране не было наглядных крупных карточек разделов, системной информации в реальном времени (емкость SD/NAND, статус базы) и быстрых действий.
4. **Сложность ориентации в каталоге:** Длинные списки игр без категорийных и жанровых плашек («Основные разделы», «Жанровые подборки», «Новинки», «Топ-100»).
5. **Ограниченная подсказка кнопок управления:** Не было постоянного элегантного футера с индикатором заряда, часов, Wi-Fi и контекстных подсказок Joy-Con.

3. Сохранении 100% совместимости со всей бизнес-логикой и структурой данных.
