# Architectural Decision Records (ADRs) — Keep The Why

## ADR-001: Video Encoding Profile (H.264 High Profile 720p 30fps)

### Status: Accepted
### Context
4IFIR runs video backgrounds in the home menu and overlay. We must choose an encoding profile for all assets in the catalog and generated by H3H Studio.

### Decision
Adopt **H.264 (AVC) High Profile, Level 4.1, 1280x720, 30fps CFR, yuv420p, moov atom at beginning (`+faststart`)** as the primary recommended standard, with 60fps allowed for high-motion gameplay clips.

### Constraints & Rejected Alternatives
1. **Rejected: HEVC (H.265) as default.**
   - *Why rejected:* Although Tegra X1 has an HEVC decoder, hardware initialization latency is higher, and HEVC decoder power draw can cause clock pacing spikes when waking up from menu sleep. H.264 provides near-instant keyframe decoding and universal compatibility across all Switch Atmosphere / 4IFIR versions.
2. **Rejected: 1080p as mandatory.**
   - *Why rejected:* The handheld screen is physically 1280x720. In docked mode, 720p upscaled by Switch hardware looks crisp while consuming less than half the memory bandwidth and micro-SD read throughput. 1080p is permitted only for users who specifically request it in Studio.
3. **Rejected: 10-bit color (`yuv420p10le`).**
   - *Why rejected:* Forces software decoding fallback on many homebrew overlay players, causing 100% CPU lockup and severe dropped frames.

## ADR-002: Switch UI Rendering Architecture (SDL2 over Web/ImGui)

### Status: Accepted
### Context
A GUI framework is required for the Switch Homebrew application.

### Decision
Use **SDL2** with `SDL_Renderer` hardware acceleration and standard `SDL_ttf` / `SDL_image`.

### Constraints & Rejected Alternatives
1. **Rejected: Web / Chromium Embedded / HTML UI on Switch.**
   - *Why rejected:* Excessive memory consumption (> 150 MB), unusable in Applet Mode (where available heap is limited to 32–400 MB), slow boot time.
2. **Rejected: Raw Dear ImGui.**
   - *Why rejected:* Dear ImGui is designed for developer debugging overlays, not high-contrast, polished consumer console UIs. Navigating complex multi-pane lists with Joy-Con D-Pad in ImGui requires heavy custom focus trees.
3. **Chosen: Clean SDL2 Layer with Dedicated Focus Tree.**
   - *Why chosen:* Direct access to hardware surfaces, predictable 60fps VSync, precise memory budgeting (< 15 MB base heap), native Joy-Con axis and button mapping via standard SDL2 GameController API.

## ADR-003: Storage Layout & Atomic Commit Rollback Mechanism

### Status: Accepted
### Context
Replacing or installing a video background could be interrupted by power loss, SD card removal, or network disconnection. Furthermore, users may have custom backgrounds that they do not want to lose.

### Decision
Implement a 3-stage atomic transaction:
1. Stream download to `sdmc:/recordings/covers/<TITLEID>.tmp`.
2. Verify size and SHA-256 digest against catalog specification.
3. If `<TITLEID>.mp4` exists, rename to `<TITLEID>.bak`.
4. Rename `<TITLEID>.tmp` to `<TITLEID>.mp4`.
5. Provide a one-click `[X] Restore Backup` option in UI.

### Constraints & Rejected Alternatives
1. **Rejected: In-place streaming directly to `<TITLEID>.mp4`.**
   - *Why rejected:* An interrupted download leaves a zero-byte or corrupt file. 4IFIR's video player could crash or display a black screen on boot.
2. **Rejected: Overwrite without backup.**
   - *Why rejected:* Destroys existing user files irreversibly. Keeping a single `.bak` guarantees zero data loss with minimal storage overhead.

## ADR-004: Versioned Catalog JSON Schema and Static GitHub Hosting

### Status: Accepted
### Context
The catalog must be consumed by both the web library and the Switch Homebrew app.

### Decision
Host `catalog.json` statically on GitHub Pages with strict JSON Schema (`catalog.v1.schema.json`).

### Constraints & Rejected Alternatives
1. **Rejected: Complex custom dynamic REST API (Node/Python backend) for read operations.**
   - *Why rejected:* Requires ongoing server hosting costs, uptime maintenance, and introduces an external point of failure. A static versioned JSON hosted on GitHub Pages / CDN is free, provides 99.99% availability, supports HTTP caching headers, and can be queried directly by both Switch and Web.
2. **Rejected: Unversioned JSON schema.**
   - *Why rejected:* Breaking schema changes in future versions would crash older versions of the Switch downloader running on consoles. A schema version number (`schemaVersion: 1`) allows safe client-side migrations.

## ADR-005: Community Moderation Workflow

### Status: Accepted
### Context
Allowing community-submitted video backgrounds without risking quality degradation, malware, copyright infringement, or invalid video encodings.

### Decision
Staged moderation pipeline:
`Pending Submission -> Automated FFprobe/Checksum Check in CI -> Maintainer Review -> Merge into catalog.json`.

### Constraints & Rejected Alternatives
1. **Rejected: Automatic publishing from public upload forms.**
   - *Why rejected:* Invites spam, copyright strikes, inappropriate content, and corrupt MP4 files that would crash consoles.
2. **Chosen: GitHub-native moderation workflow (Issues/PRs with automated CI checks).**
   - *Why chosen:* Transparent, fully audited, reproducible, and requires zero paid infrastructure.
