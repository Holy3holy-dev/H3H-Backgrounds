# 🤖 H3H Backgrounds & After Dark — Telegram Uploader Bot

Telegram-бот для краудсорсинга и автоматического добавления живых видеофонов от сообщества прямо в каталог **H3H Backgrounds** и **H3H After Dark (18+)** на Nintendo Switch (4IFIR).

---

## ⚡️ Возможности бота:
1. **Приём любых видео и анимаций:**
   - Поддерживает форматы: `.mp4`, `.webm`, `.mov`, `.gif`.
2. **Интеллектуальный TitleIdResolver:**
   - Пользователь пишет название игры на русском или английском (например: *«Зельда ТОТК»*, *«NieR 2B»*, *«Ведьмак»*, *«Марио»*), и бот автоматически находит официальный 16-значный **Title ID** Nintendo Switch!
   - Поддерживает ручной ввод Title ID.
   - Поддерживает режим **«Свободный фон»** для After Dark (чтобы фон можно было привязать к любой игре на консоли).
3. **Автоматическая конвертация через FFmpeg:**
   - Пережимает видео в нативный для Switch **1280x720 30fps H.264** с флагом `+faststart`.
   - Генерирует миниатюру превью `.jpg`.
4. **Загрузка в Google Drive и публикация на GitHub:**
   - Заливает готовый ролик в Google Диск и получает прямую ссылку.
   - Записывает метаданные в `catalog/data/catalog.json` или `catalog/data/catalog_after_dark.json`.
   - Делает коммит и пушит в репозиторий GitHub — ролик мгновенно появляется у всех пользователей на Switch!

---

## 🚀 Как запустить бота за 2 минуты:

### Шаг 1: Создайте бота в Telegram
1. Откройте **[@BotFather](https://t.me/botfather)** в Telegram.
2. Отправьте команду `/newbot`.
3. Введите имя (например: `H3H Backgrounds Uploader`) и юзернейм (например: `h3h_backgrounds_bot`).
4. Скопируйте полученный **HTTP API Token** (вида `7123456789:AAH...`).

### Шаг 2: Вставьте токен
Откройте файл `tg_bot/config.py` и вставьте ваш токен в строку:
```python
BOT_TOKEN = "ВАШ_ТОКЕН_ИЗ_BOTFATHER"
```
*(Либо передайте через переменную окружения `set BOT_TOKEN=ВАШ_ТОКЕН`)*

### Шаг 3: Запустите бота
В командной строке или терминале в корне проекта выполните:
```bash
py -3 tg_bot/bot.py
```

Готово! Теперь любой подписчик вашего канала может отправить боту ролик, и он автоматически появится на Nintendo Switch!
