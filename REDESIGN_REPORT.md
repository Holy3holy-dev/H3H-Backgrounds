# ИТОГОВЫЙ ОТЧЁТ О РЕДИЗАЙНЕ: H3H-Backgrounds и H3H-AfterDark

**Дата:** 29 октября 2026 г.  
**Ветка:** `feature/redesign-ui-torrentshop` (Тестовый изолированный режим, без публикации стабильных релизов)  
**Концептуальный референс:** `TorrentShopNX` (эргономичный дашборд, 5 основных тайлов, карточные подборки, единый статус-бар)  
**Дизайн-система:** Экосистема 4IFIR Cyber-Glass (Electric Cyan для Main, Cyber-Pink для After Dark)

---

## 1. Введение и цели редизайна

Целью задачи являлся полный комплексный редизайн клиентских homebrew-приложений Nintendo Switch:
1. **H3H-Backgrounds** (`H3H-Backgrounds.nro`) — основное приложение для загрузки и менеджмента живых видеофонов.
2. **H3H-AfterDark** (`H3H-AfterDark.nro`) — версия приложения с контентом After Dark (18+).

Работа выполнена строго в тестовом режиме:
- Создана резервная копия оригинальных исходников (`backup_before_redesign/`).
- Разработка велась в изолированной git-ветке `feature/redesign-ui-torrentshop`.
- Никаких публикаций в публичные каналы, релизы GitHub или перезаписи релизных ассетов не производилось.

## 2. Ключевые архитектурные изменения

### 2.1. Дашборд главного экрана (в стиле TorrentShopNX)
- Верхний информационный статус-бар:
  - Имя приложения, неоновый индикатор и тег-бейдж (`NX v1.4.0` / `18+ v1.4.0`).
  - Онлайн-статистика: количество доступных игр и видеоиконок в каталоге, дата обновления базы.
  - Динамический расчет памяти MicroSD и системной памяти NAND в реальном времени (`SD: XX.X GB / XX.X GB • NAND: 5.3 GB / 9.4 GB`).
- 5 крупных интерактивных тайлов в горизонтальном ряду:
  1. **Каталог** (`📁`) — Каталог видеофонов и жанровые коллекции.
  2. **Видеоиконки** (`🔲`) — Выделенный раздел анимированных иконок 1:1.
  3. **Менеджер игр** (`🎮`) — Библиотека установленных на Switch тайтлов и статусы.
  4. **Загрузки** (`📥`) — Многопоточная очередь скачивания cURL с прогрессом и скоростью.
  5. **Настройки** (`⚙️`) — Управление хранилищем, проверка целостности, OTA-обновления.
- Нижняя панель с 3 контекстными карточками сводки:
  - Левая карточка: детальная статистика раздела под активным тайлом.
  - Центральная карточка: жанры и платформы каталога.
  - Правая карточка: путь целевой директории 4IFIR на SD (`sdmc:/recordings/covers` или `sdmc:/recordings/icons`) и действие по кнопке `(A)`.

### 2.2. Новый постоянный статус-бар (Универсальный футер)
- Фиксирован внизу экрана на всех экранах (координата `y=665`, высота `55px`).
- Слева:
  - Индикатор батареи с динамическим заполнением уровня заряда и цветом (зеленый/янтарный/красный) + точный процент (`%`).
  - Статус сети Wi-Fi (`Онлайн` / `Автономно`).
  - Часы реального времени (`HH:MM:SS`) из системного таймера.
- Справа:
  - Контекстные Joy-Con подсказки: `(+) Сканер целостности`, `(-) Фильтр / Поиск`, `(B) Назад / Главное меню`, `(A) Выбрать`.

### 2.3. Выделенный самостоятельный раздел «Видеоиконки» (Этап 5)
- Создан отдельный экран `renderTabVideoIcons()` (`Tab::VideoIcons`):
  - Каталог игр с поддержкой видеоиконок (112 тайтлов, 433 вариации иконок).
  - Карточки с квадратным контейнером предпросмотра 1:1 (`256x256`, HEVC 30 FPS).
  - Название игры, TitleID (16-hex), количество доступных вариантов и спецификации кодека.
  - Индикация статуса: если иконка присутствует в `sdmc:/recordings/icons/<TitleID>.mp4`, отображается яркий неоновый бейдж `✔ УСТАНОВЛЕНО`.
  - Управление:
    - `(A)`: Установка иконки напрямую в `sdmc:/recordings/icons/<TitleID>.mp4` через механизм `queueDownloadIconOnly`.
    - `(X)`: Интерактивный предпросмотр видеоиконки на весь экран с циклическим воспроизведением через FFmpeg.
    - `(Y)`: Полнотекстовый поиск через виртуальную клавиатуру `swkbd`.
    - `(-)`: Циклическое переключение фильтра (Все -> Установленные -> Не установленные).
    - `(ZL/ZR)`: Быстрая прокрутка списка на ±5 позиций.
    - `(B)`: Возврат на дашборд.

### 2.4. Редизайн каталога: категории и подборки (Этап 2 & 3)
- Экран каталога поддерживает два режима:
  1. **Режим категорий (`CatalogViewMode::Categories`)**:
     - Блок `| ОСНОВНЫЕ РАЗДЕЛЫ`: «Весь каталог» (все игры), «Избранное» (сохраненные), «Новые релизы» (свежие), «Топ-100» (лучшие по Metacritic).
     - Блок `| ЖАНРОВЫЕ И ТЕМАТИЧЕСКИЕ ПОДБОРКИ`: сетка из 14 жанров (Экшены, Аркады, Хорроры, Метроидвании, RPG, Шутеры, Платформеры и т.д.).
  2. **Режим списка игр (`CatalogViewMode::GameGrid`)**:
     - Список видеофонов выбранной категории с фильтрами, переключением вариантов и возвратом по `(B)`.

### 2.5. Модуль обновления приложений (OTA Updates, Этап 6)
- Реализован транзакционный механизм обновления в `App::checkForUpdates()` и `App::updateApplicationNro()`:
  - Загрузка во временный файл `<TargetNro>.new` или `.tmp`.
  - Проверка валидности заголовка NRO: чтение магического идентификатора `NRO0` по смещению `0x10` и проверка минимального размера файла (>= 15 МБ).
  - Создание резервной копии `<TargetNro>.bak`.
  - Атомарная замена исполняемого файла.
  - Автоматический откат из `.bak` в случае сбоя или повреждения сети.
  - Диалоговое окно с подтверждением и предложением перезапуска.

## 4. Сборка и бинарные артефакты

Оба приложения успешно скомпилированы под архитектуру ARM64 Nintendo Switch с помощью тулчейна devkitA64 (GCC 16.1.0, `elf2nro`, `nacptool`):

| Приложение | Файл NRO | Размер бинарника | Сигнатура заголовка | Статус сборки |
|---|---|---|---|---|
| **H3H Backgrounds (Main)** | `downloader/H3H-Backgrounds.nro` | **26,538,812 байт** | `NRO0` @ 0x10 | **SUCCESS (0 ошибок)** |
| **H3H After Dark (18+)** | `downloader/H3H-AfterDark.nro` | **26,538,037 байт** | `NRO0` @ 0x10 | **SUCCESS (0 ошибок)** |

Кодовая база на 100% едина: After Dark собирается с препроцессорным флагом `-DH3H_AFTER_DARK`, автоматически переключая палитру на Cyber-Pink (`#FF2E93`), каталог на `catalog_after_dark.json` и рабочую директорию на `sdmc:/switch/H3H-AfterDark/`.

## 6. Руководство по тестированию на консоли

1. Скопируйте тестовые бинарники на MicroSD карту Switch:
   - `downloader/H3H-Backgrounds.nro` -> `sdmc:/switch/H3H-Backgrounds/H3H-Backgrounds.nro`
   - `downloader/H3H-AfterDark.nro` -> `sdmc:/switch/H3H-AfterDark/H3H-AfterDark.nro`
2. Запустите через Homebrew Launcher (желательно в режиме полного доступа к памяти через удержание кнопки `[R]` при запуске любой установленной игры).
3. **Проверка дашборда:**
   - Навигация по 5 тайлам (`DPAD Влево / Вправо`), открытие каждого раздела по кнопке `(A)`.
   - Проверка отображения свободного места SD и NAND в правом верхнем углу.
4. **Проверка раздела «Видеоиконки»:**
   - Откройте второй тайл «Видеоиконки».
   - Убедитесь в наличии миниатюр 1:1, индикатора `✔ УСТАНОВЛЕНО` для уже имеющихся иконок.
   - Нажмите `(X)` для проверки полноэкранного воспроизведения видеоиконки.
   - Нажмите `(A)` для добавления иконки в очередь загрузок и проверки установки в `sdmc:/recordings/icons/<TitleID>.mp4`.
   - Нажмите `(-)` для переключения фильтров (Все / Установленные / Не установленные).
5. **Проверка каталога:**
   - Откройте первый тайл «Каталог».
   - Убедитесь в отображении 4 основных разделов и 14 жанровых категорий.
   - Нажмите `(A)` на любой категории для перехода к сетке игр, затем `(B)` для возврата к категориям.
6. **Возврат на главный экран:**
   - Из любого раздела нажатие кнопки `(B)` возвращает на дашборд.
   - На дашборде нажатие `(B)` закрывает приложение и возвращает в hbmenu.

## 7. Безопасность и сохранение пользовательских данных

- **Сохранность путей:** Пути установки видеофонов (`sdmc:/recordings/covers/`) и видеоиконок (`sdmc:/recordings/icons/`) полностью сохранены. Ни один существующий файл пользователя не перезаписывается без создания резервной копии `.bak`.
- **Изоляция веток:** Все изменения локализованы в ветке `feature/redesign-ui-torrentshop`. Ветка `main` и публичные релизы GitHub не затрагивались.
- **Бэкап:** Полная исходная резервная копия сохранена в папке `backup_before_redesign/`.
